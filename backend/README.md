# Meetly — сервер

NestJS, TypeScript, Prisma и SQL Server. Исходники находятся в `src`, команды обслуживания каталога — в `scripts`. JSDoc в коде описывает назначение методов, параметры, результаты и ограничения доступа.

## Запуск и настройки

Из папки `backend`: `npm ci`, `npm run db:generate`, затем `npm run build` и `npm start`. Для разработки — `npm run dev`. Миграции применяются отдельно: `npm run db:migrate`.

Скопируйте `.env.example` в `.env` и задайте реальные настройки. Существующий `.env` перезаписывать не требуется.

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | Соединение Prisma с SQL Server; только на сервере |
| `JWT_SECRET` | Случайный секрет подписи токенов длиной не менее 32 символов |
| `PORT` | Порт HTTP-сервера, по умолчанию 3000 |
| `PUBLIC_URL` | Адрес бэкенда, доступный клиентскому устройству; используется для ссылок на файлы |
| `WEB_ORIGINS` | Разрешённые источники веб-клиента через запятую |
| `GEOAPIFY_API_KEY` | Серверный ключ фона карты; для поиска ресторанов не нужен |

Реальные `.env` и `.env.*` исключены из Git; `.env.example` разрешён и содержит только примеры. Переменные фронтенда `EXPO_PUBLIC_*` доступны пользователю приложения и не подходят для секретов. Ключи Яндекса больше не используются и удалены из локального серверного `.env`.

Swagger формируется из кода сервера: `/api/docs`, схема — `/api/docs-json`.

## Проверки

`npm test` собирает сервер и запускает `test/*.test.cjs`. HTTP-интеграционные проверки используют SQL Server из `DATABASE_URL`; для отдельного тестового стенда задайте адрес тестовой БД в окружении процесса. Нужны применённые миграции. Тесты каталога ожидают установленные 200 заведений. Новые проверки создают собственные аккаунты, встречи и файлы и удаляют их через завершающий обработчик; каталог не импортируют и существующие пользовательские записи не очищают.

| Проверки | Что подтверждают |
|---|---|
| `auth-security.test.cjs` | Хеш пароля и refresh-токена, нормализацию email, конкурентный refresh, отзыв access-токена, истечение сессии |
| `chat-files-security.test.cjs` | Страницы истории без дублей и пропусков, изоляцию встреч, недействительные курсоры, права на аватары и вложения, срок и назначение подписанных ссылок, отзыв доступа удалённого участника, ограничения размера и MIME |
| `invitations.test.cjs` | Истечение и отзыв приглашений, повторное принятие без дублей, запрет вступления после выбора места |
| `transactions.test.cjs` | Serializable и ограниченные повторы только для P2034; остальные ошибки не повторяются |
| `error-responses.test.cjs` | Стабильные статусы Prisma и отсутствие внутренних диагностик в публичном ответе 500 |
| `api.test.cjs` | Сквозной сценарий аккаунтов, встреч, прав, голосов, Socket.IO, чата, файлов, календаря и брони |
| `catalog-filters.test.cjs` | Полноту фильтров БД, несколько кухонь, предпочтения участников и скрытие старого уведомления |
| Остальные `*.test.cjs` | Правила голосования и дат, подбор, ICS, загрузку каталога, тайлы и фотографии |

Проверка исходных снимков пропускается, если они удалены. Работа приложения и HTTP-проверки каталога используют БД. Внешние HTTP-ответы в модульных проверках подменяются; эти тесты не доказывают доступность публичных поставщиков.

## Каталог

`npm run catalog:fetch` скачивает исходные данные. `npm run catalog:import -- --dry-run` проверяет отбор без изменения БД. `npm run catalog:import` применяет отбор. `npm run catalog:photos` обновляет общие фотографии в ассетах фронтенда.

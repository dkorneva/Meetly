# Meetly

Meetly — мобильное приложение для организации встреч: выбора даты и места, голосования за заведение и общения участников. Клиент разработан на React Native, TypeScript и Expo; для браузера используется React Native Web.

## Возможности

- Создание и редактирование встреч, просмотр активных и завершённых встреч.
- Поиск и фильтрация заведений, голосование за место встречи.
- Управление участниками, сообщения, реакции и выбор файлов для вложений.
- Просмотр контактов заведений и управление бронированием.
- Редактирование профиля, выбор фотографии, светлая и тёмная темы.
- Сохранение пользовательских данных и настроек между запусками.

## Запуск

Необходимы Node.js и npm. Команды выполняются из корня проекта:

```sh
npm ci
npm start
```

Для запуска на телефоне откройте QR-код из терминала в совместимой версии Expo Go. При подключении по локальной сети телефон и компьютер должны находиться в одной сети.

```sh
npm run android    # запуск через Expo на Android
npm run web        # запуск в браузере
npm run export:web # сборка веб-версии в dist/
```

## Структура

Исходный код организован по Feature-Sliced Design:

| Каталог | Назначение |
| --- | --- |
| `src/app/` | Инициализация, управление общим состоянием и навигация |
| `src/pages/` | Экраны приложения и проверка полей форм |
| `src/widgets/` | Шапка, нижняя навигация и контейнер диалогов |
| `src/features/` | Бронирование, приглашения, фильтры и другие действия пользователя |
| `src/entities/` | Модели встреч, заведений и сообщений, предметная логика |
| `src/shared/` | Общие компоненты, тема, проверки и взаимодействие с устройством |

Зависимости направлены от верхних слоёв к нижним. Слайсы доступны через публичные `index.ts`. Ресурсы находятся в `assets/`, тесты — в `tests/`.

## Проверки

```sh
npm test              # все автоматизированные тесты
npm run test:watch    # повторный запуск при изменениях
npm run test:coverage # отчёт покрытия
npm run typecheck     # проверка TypeScript
npm run check:fsd     # проверка зависимостей между слоями и слайсами
```

Тесты используют Jest, jest-expo и React Native Testing Library. Проверки экранов, диалогов и виджетов находятся в `tests/pages/`, `tests/features/` и `tests/widgets/`. Общие компоненты проверяются в `ui.test.tsx`, сборка приложения — в `app.test.tsx`, изменение клиентского состояния — в `controller*.test.tsx`.

Для изолированного запуска тестов используются подмены системных функций устройства и хранилище в памяти. HTML-отчёт покрытия создаётся в `coverage/lcov-report/index.html`.

## Документация кода

Назначение функций, параметры и результаты описаны в JSDoc; типы задаются средствами TypeScript.

```sh
npm run docs
```

Команда обновляет [справочник сигнатур](SIGNATURES.md) и создаёт HTML-документацию TypeDoc в `docs/api/index.html`. Сгенерированный HTML не включается в Git.
